# Server Commands

> Maintenance note: whenever server commands/scripts are added or changed in `package.json`, update this file in the same change.

## Setup

```powershell
cd c:\Projects\Backend_Api\server
npm install
```

## Run Dev Server

```powershell
cd c:\Projects\Backend_Api\server
npm run dev
```

## Build And Run Production

```powershell
cd c:\Projects\Backend_Api\server
npm run build
npm start
```

## OpenAPI

```powershell
cd c:\Projects\Backend_Api\server
npm run openapi
```

## Seed Data

```powershell
cd c:\Projects\Backend_Api\server
npm run seed
npm run seed:demo
```
